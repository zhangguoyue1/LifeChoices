## 概念祛魅

"落户一线"的难，在于户口把教育、医疗、购房资格一次性绑定，同时意味着放弃老家的福利与人脉。一次落户，长期锁定。

:::io
@输入
- 写下目标城市户口绑定的具体权益（学区、购房、医保）与老家放弃的权益。
- 写下你在该城长期定居的真实概率。
- 硬问题：若落户后你又离开该城，这户口还剩多少价值？
@输出
**一、权益看绑定。** 户口价值主要在学区与购房资格 [REF-001]。
**二、放弃有价。** 老家的福利与人脉一旦迁出，重建难 [REF-002]。
**三、定居概率定价值。** 不确定长留，户口的锁定成本高于收益 [REF-003]。
:::

:::case pos 案例 A-01｜核验定居概率后落
确认在该城购房成家、孩子将入学，才落户口，户籍与学区对齐，避免"落了又走"的浪费。
:::

## 两条路线：收益与代价盘点

下表把"落一线""不落（保留老家）""折中（人才户/集体户）"摊开。

| 维度 | 路线 A：落一线 | 路线 B：留老家 | 路线 C：折中户 |
| --- | --- | --- | --- |
| 显性收益 | 学区/购房资格 | 保老家福利人脉 | 过渡灵活 |
| 显性代价 | 放弃老家；锁定 | 错失一线资格 | 部分权益受限 |
| 隐性长期代价（3–10 年） | 若离开价值缩水 [REF-003] | 孩子教育受户籍限 [REF-001] | 几乎无 |
| 现金曲线 | 购房前置 | 省前置 | 中 |
| 可逆性 | **高不可逆**：迁回难 [REF-002] | **不可逆** | **半可逆** |

:::io
@输入
动表前填：①一线绑定权益；②老家放弃权益；③定居概率；④孩子教育时间线。
@输出
三个最易忽略的账：
- **锁定效应**：落了又走，迁移成本与户籍价值双损 [REF-002]。
- **教育时间线**：孩子入学节点决定户口的紧迫度 [REF-001]。
- **老家流失**：迁出后宅基地、医保、人脉重建难 [REF-002]。
@依据
户籍与教育、购房资格绑定的城市差异显著，迁移涉及权益重排 [REF-001]。
:::

## 核心自检工具包

从动机到资源到耐受到长期视角。

### 组一 · 动机层

#### 工具 1.1 落户动机检查

:::check 逐项判断你"想落"的真实动因（可多选）
- 我有明确的孩子入学时间线
- 我主要因为有"一线身份"面子
- 我其实没算过老家放弃账
- 我不确定能否长期定居
- 我分不清"该落"和"想落"
- 周围人都落了
:::

:::io
@输入
把勾中的项分绿色（学区/事实）与黄色（面子/不确定），数黄色是否超绿色。
@输出
<span class="light green">绿灯</span> 绿主导+时间线：可落。
<span class="light amber">黄灯</span> 黄接近超绿：你落的是身份不是需求。
<span class="light red">红灯</span> "不确定/分不清"主导：动机被裹挟。
:::

#### 工具 1.2 定居测试

:::io
@输入
写：**若三年后你离开该城，这户口还值吗？** 只答：值／贬／废。
@输出
- 废 → 优先 B/C，不硬落。
- 值 → 评估 A 的真实权益。
:::

### 组二 · 资源容错层

#### 工具 2.1 权益核对

:::io
@输入
列一线绑定权益与老家放弃权益，标紧迫度。
@输出
无明确时间线 → 不急落，优先 C [REF-001]。
:::

#### 工具 2.2 定居与家庭

:::check 逐项评估（勾选已确认或高概率）
- 我确定在该城定居概率高
- 我有孩子入学时间线
- 我了解老家权益放弃后果
- 我有折中户（人才/集体）选项
:::

### 组三 · 耐受底线层

#### 工具 3.1 落户时机

:::io
@输入
写死：落户触发线（如购房/入学前 N 月）、不落的退出。
@输出
把"落"设触发，避免提前锁定。
:::

#### 工具 3.2 退出成本底线

:::check 把三个写死（填完拍照）
- 我设定的落户触发线是 ______
- 我能接受的迁移次数是 ______
- 我承诺：不确定定居先走折中户
:::

### 组四 · 10-10-10 长期视角层

:::io
@输入
对"落/不落"分三次各写一句：10 年后怎么看？
@输出
两档一致 → 稳；只"现在"强 → 面子驱动。
:::

## 高频思维陷阱黑名单

下面 7 条最高频认知错误。

| 陷阱 | 错在哪 | 识别信号 |
| --- | --- | --- |
| 身份面子 | 为"一线人"落 | "落了才算站稳" |
| 时间盲 | 没算入学节点 | "迟早要落" |
| 老家盲 | 忽略放弃账 | "老家没用" |
| 虚假二分 | 压成"落或不落" | "不落就白拼" |
| 幸存者偏差 | 只看见落户受益 | 没聊过落了又走的 |
| 确认偏误 | 只搜一边 | 信息源单一 |
| 跟风落 | 因别人落 | "身边都落了" |

:::io
@输入
翻出最近想法对照。
@输出
命中 3 条以上：判断被面子劫持，读完案例再重做 [REF-003]。
:::

## 非二元：分步折中方案库

之间 3 个中间态。

| 方案 | 适用人群 | 操作步骤 | 试错成本 | 退出方式 |
| --- | --- | --- | --- | --- |
| 1. 落一线 | 定居确 | 入学/购房前落 | 高不可逆 | 迁回难 |
| 2. 留老家 | 不定居 | 保权益 | 不可逆 | 后期可落 |
| 3. 折中户 | 说不清 | 人才/集体户过渡 | 半可逆 | 确定再转 |

:::io
@输入
你的动机（1.1）、权益（2.1）、定居（2.2）。
@输出
匹配：黄主导 → 3；定居确 → 1；不定居 → 2。反直觉：**方案 3 比硬落更稳**——不确定先过渡 [REF-001]。
:::

## 暂缓决策红灯判定

以下 7 条，勾中数决定资格。

:::check 情绪与条件状态自检（勾选符合项）
- 近一个月因这事睡眠异常
- 落户口主因是面子
- 还没核对老家放弃账
- "分不清该落/想落"
- 定居不确定
- 被跟风落
- 无入学时间线
- 有未处理问题
:::

:::io
@输出
- 命中 0–2：具备条件，推进。
- 命中 3–5：进 **30 天冷静期**，只核权益与定居概率。
- 命中 ≥6：进 **90 天**，优先厘清动机 [REF-004]。
@依据
急性压力高估身份光环、低估锁定与放弃 [REF-004]。
:::

## 兜底退出预案模板

做决定前填完。

:::io
@输入
假设落户后第 3 年需重评，盘点：权益、定居、老家、退路。
@输出
三段退场：
**一、止损线**：落户触发 ___；迁移次数 ≤ ___；出现 ___ 即重评。
**二、退出顺序**：先退增量（折中户）→ 再退时机（时间线）→ 最后退硬落（仅前两步失效）。
**三、最低保障**：保留老家退路；留折中选项；独立资金。
@依据
事前锁触发与退路，对抗落户无底 [REF-001] [REF-002]。
:::

## 脱敏真实案例库

三个案例。

:::case pos 案例 C-01｜顺利型：按时间线落
**输入**：定居确，入学节点近。
**选择**：方案 1。
**复盘**：户籍学区对齐，无浪费。
**经验**：到点再落。

:::case neg 案例 C-02｜踩坑型：面子硬落又走
**输入**：面子落，不定居。
**选择**：路线 A。
**复盘**：2 年离开，户籍贬值迁回难。
**经验**：落=锁 [REF-002]。

:::case mid 案例 C-03｜折中型：折中户过渡
**输入**：说不清，先人才户。
**选择**：方案 3。
**复盘**：确定定居后转，灵活。
**经验**：不确定先过渡。
:::
