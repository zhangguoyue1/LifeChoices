Life Choices Reference

人生关键处，
缺的从来不是答案，是算法。

这里不生产结论。这里提供一套可以反复使用的决策工序：把模糊的"要不要"，拆成可清点的输入、可验证的依据、可量化的代价，和可退出的路径。

大多数人生建议的问题，不在于它错，而在于它不可证伪、也不可执行。
所以我们只写能算、能查、能写完就扔掉的东西。
POSITIONING

01两个系列，两种处境

同一个站点体系下的两套内容，处理的是完全不同的人生状态。走错门，会用错工具。

《高性价比人生指南》· 稳态优化

适用于方向已定、只求更省力的阶段。把已有的生活调得更划算：收入结构、时间分配、消费效率、日常习惯。核心是在既定轨道上降低摩擦，改错了代价有限，随时可调回。

《人生抉择参考手册》· 拐点抉择

适用于轨道本身要不要换的阶段。转行、婚育、迁移、止损。核心是识别不可逆性、核算滞后成本、预留退出路径。这类决定做错，不是效率问题，是几年时间回不来。

BASE TOOLKIT

02四个底层工具，先学会再翻目录

每一篇专题都会反复调用这四个工具。它们不解决具体问题，但决定你有没有资格现在做决定。

工具一 · 可逆性分级

输入写下这个决定：做错之后，恢复原状需要多久、多少钱、是否损伤不可再生资源（年龄、生育窗口、健康、信誉）。
输出三档判定 —— 可逆（3 个月内可完全回退，如换岗、做副业）／半可逆（需 1–3 年且伴随收入或资历折损，如转行、读研）／高不可逆（结构性改变，回流成本极高，如生育、离婚、卖房）。
依据决策理论中的"可逆性偏好"：在信息不足时，优先选择可撤回的选项，等价于用低成本购买信息。行为经济学亦指出人系统性低估不可逆决定的后悔成本 REF-101。

工具二 · 10-10-10 三时点

输入对同一个选项，分别回答：10 分钟后我怎么看？10 个月后我怎么看？10 年后我怎么看？三次作答必须分开写，不许一次写完。
输出若三档判断方向一致 → 动机稳定；若"10 分钟"强烈、而"10 年"无感 → 多为情绪驱动，非真实偏好；若"10 年"清晰、"10 分钟"痛苦 → 属于典型的短期代价换长期结构，需要的是耐受方案而不是放弃。
依据10-10-10 法则（Suzy Welch）用于剥离当下情绪对判断的加权；其有效性的心理学基础是人在不同时间距离下对同一事件的解释层级不同（解释水平理论）REF-102。

工具三 · 情绪隔离期

输入记录最近 30 天的睡眠时长、是否经历重大负面事件（分手、亲人病故、被裁、体检异常）、以及"想改变"的念头是否集中在深夜或争吵之后。
输出命中任一项 → 进入冷静期，禁止拍板。冷静期内只做信息收集，不做承诺（不签字、不辞职、不转账、不告知家人已定）。
依据情绪状态会窄化注意力与时间视野（稀缺心态），使人在"逃离当下"与"追求长期"之间系统性偏向逃离 REF-103；急性压力下前额叶控制功能下降，风险偏好发生偏移。

工具四 · 容错资本公式

输入可动用现金（不含应急金以外的不动产、不含借来的钱）÷ 月刚性支出（房贷/房租 + 基本生活 + 保险 + 各类还款）= 缓冲月数；再乘以"家庭支持系数"（无人分担 0.7／部分分担 1.0／可兜底 1.3）。
输出红灯 有效缓冲 < 3 个月：不具备任何试错资格，先修现金流。黄灯 3–6 个月：只能做可逆选项。绿灯 ≥ 9 个月：可进入半可逆决策。跨行业、跨城市、创业类，建议按 12 个月估算。
依据风险缓冲与机会成本的基本核算逻辑：决策能力受流动性约束，而非受决心约束；缓冲不足时人会被迫在坏时点接受坏条件，把"选择"退化为"接受" REF-104。

HOW TO USE

04怎么用这个站

  1. 先读可逆性等级，再读正文。标注"高不可逆"的篇目，请至少留 90 天；标注"可逆"的，可以直接去试，试错本身就是最便宜的信息来源。
  2. 认准 REF 标记。正文里的 REF-101 这类灰色小标，点击会跳到页面底部对应的证据条目。四类来源：学术文献、官方法规、权威调研、统计报告。标"强证据"的是可直接引用的正式文献或法规原文，标"辅助"的是行业报告与深度纪实，只作参考。
  3. 自检清单可以直接勾、直接复制。带复选框的清单支持点击打勾，右上角"复制清单"会把纯文本复制到剪贴板，方便贴进备忘录、纸质打印，或者发给需要一起承担后果的人。
  4. 遵守冷静期规则。每篇标了建议冷静期（14／30／60／90 天）。冷静期的意思不是"忍着",而是"这段时间只允许收集信息，不允许做承诺"。
  5. 不追求一次想清楚。这套工具的目标不是让你获得确定感，而是让你在不确定中，用最小的代价把下一步走出来。能小步试的，不要用一次大决定去赌。
